# @webship.co/workspace-wekan

Wekan, the open-source kanban board, for the [Webship Workspace](https://github.com/webship/workspace) dashboard. It
brings a builder that makes a real Wekan site in containers (DDEV by default) from Wekan's own image, with its
database, its default accounts and a sample board, the Wekan step pack wired into the workspace's testing setup, and
its cards as work items of the tracker family
([`@webship.co/workspace-tracker`](https://github.com/webship/workspace-tracker)): read one, analyze it, and let the
workspace's AI CLI work it on a branch, with a person in charge.

The builder, the provider, the tests and CI come with the first release, `1.0.0`.
